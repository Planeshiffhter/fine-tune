CONFIRMED AND REPAIRED
SEC-01 - Unbounded automatic test discovery.
  Starting npm test was bare node --test. Workspace exclusions did not prevent
  future archived JS from discovery. The new command enumerates four maintained
  test files. A controlled archive sentinel failed under bare discovery, and the
  maintained suite passed32tests while excluding it. Sentinel was then removed.
  Continue to keep sources compressed/inert; explicit imports or manual execution
  can defeat this procedural boundary. This is not an OS sandbox.
SEC-02 - Redirect request/data forwarding.
  Native fetch followed redirects after initial endpoint validation. Two loopback
  HTTP servers reproduced a307 to a different port. The Agent Server adapter sent
  its dummy X-Session-API-Key to that destination; Ollama generation and streaming
  forwarded the synthetic prompt. No real key, remote endpoint or customer data
  was used. Three regressions failed before fix; all passed after redirect:error
  in both shared request paths. Destination requests are now zero in these cases.
  Configure final endpoint URLs. Custom fetch replacements must honor the standard
  redirect option; this test does not establish DNS, proxy or arbitrary custom
  transport security. API classes/errors and retry rules remain unchanged.

UNRESOLVED / KNOWN SCOPE
SEC-03 - Agent sessions default to local /workspace. No execution isolation is
  implemented/proven. Do not run untrusted generated programs there or claim that
  transport timeout/iteration limits establish a sandbox. Select/test one runtime.
SEC-04 - API request URL parsing is outside its error catch. This is a source-review
  robustness concern, not an exercised exploit. Reproduce malformed request targets
  in a separately scoped hardening test before claiming impact or fixing behavior.
SEC-05 - Mock API is unauthenticated, without persistence, quotas or tenant controls.
  Loopback-only default is intentional; changing HOST does not make it production.
SEC-06 - Upstream archive versions/provenance need selection. OpenSandbox metadata
  differs from the historical release1.2.0 audit. No dependencies/images were
  installed/scanned to establish a real deployed security posture.
