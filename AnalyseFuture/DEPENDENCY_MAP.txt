CURRENT RUNTIME PATH
  npm run dev / npm start
    -> node apps/api/src/server.mjs
      -> node:http createServer(createHandler())
      -> apps/api/src/app.mjs
         -> @fine-tune/core -> packages/core/src/index.mjs
         -> node:fs/promises reads allowlisted assets:
            apps/web/public/index.html
            apps/web/public/app.js
            apps/web/public/styles.css

  Browser index.html imports /app.js and /styles.css.
  Browser app.js selects DOM controls from that HTML and submits JSON to
  POST /api/generate. The handler invokes generateMockProject, returning an
  in-memory index.html + README.md + mock plan + unrun verification labels.
  UI renders plan using textContent/DOM nodes, previews index.html via sandbox=""
  srcdoc, and offers a Blob/anchor download of index.html only.
  GET /api/health always reports offline_mock and model_connected:false.

INTERNAL NPM WORKSPACES
  Root: fine-tune@0.1.0, private, ESM; Node >=22.
  @fine-tune/api@0.1.0 -> @fine-tune/core@0.1.0 (the only declared package dependency).
  @fine-tune/core@0.1.0 exports ./src/index.mjs.
  @fine-tune/web@0.1.0 is a static-asset workspace with no package dependencies.
  @fine-tune/model-gateway@0.1.0 exports ./src/index.mjs; no package dependencies.
  @fine-tune/agent@0.1.0 exports ./src/index.mjs; no package dependencies.
  npm ci creates five internal @fine-tune workspace links. package-lock.json v3
  records these links; there are zero third-party npm runtime/dev dependencies.

LIBRARY BOUNDARIES PRESENT BUT NOT CALLED BY THE WEB/API GENERATION PATH
  services/model-gateway/src/index.mjs:
    createModelGateway[FromEnv] -> ModelGateway -> MockModelProvider OR
    OllamaModelProvider -> native fetch -> optional /api/chat service.
    Exports ModelGatewayError, MockModelProvider, OllamaModelProvider,
    ModelGateway, createModelGateway, createModelGatewayFromEnv.
    Uses native AbortController/DOMException/TextDecoder/performance/timers.
    generate validates messages/options/token budget, applies timeout and bounded
    non-stream retry; stream emits typed deltas/completion without replaying
    partial output. Provider-reported usage stays null when unavailable.

  services/agent/src/index.mjs:
    createOpenHandsAgentAdapterFromEnv -> OpenHandsAgentServerAdapter
    -> native fetch -> optional /api/conversations REST service.
    Exports AgentAdapterError, OpenHandsAgentServerAdapter,
    createOpenHandsAgentAdapterFromEnv.
    Supports create/get/message/run/pause/interrupt/events/final/delete;
    timeout/cancellation; bounded iterations; optional session-key header.
    It does not import model-gateway or the Python SDK. An agent's future model
    access path must be proven rather than assuming the gateway owns all calls.
    No automatic retries of lifecycle side effects.

OPTIONAL EXTERNAL SERVICES, NOT BASELINE PREREQUISITES
  Ollama HTTP endpoint: default 127.0.0.1:11434; configured model required when
  selected. Live service/model are not installed or verified by these tests.
  OpenHands Agent Server: default 127.0.0.1:8000; REST compatibility contract
  targets v1.62.0; real server/model/execution remain unverified.
  Both reject URL-embedded credentials and remote hosts by default; explicit
  operator opt-in allows remote endpoints. This is configuration validation,
  not proof of network/tenant isolation.

CONFIGURATION NAMES (NO SECRET VALUES)
  API: HOST, PORT. Defaults 127.0.0.1:3000; PORT must be an integer 0..65535.
  Gateway: MODEL_PROVIDER, MODEL_TIMEOUT_MS, MODEL_MAX_RETRIES,
           MODEL_RETRY_DELAY_MS, OLLAMA_BASE_URL, OLLAMA_MODEL,
           OLLAMA_ALLOW_REMOTE.
  Agent: OPENHANDS_BASE_URL, OPENHANDS_TIMEOUT_MS, OPENHANDS_MAX_ITERATIONS,
         OPENHANDS_ALLOW_REMOTE, OPENHANDS_SESSION_API_KEY (optional secret).
  .env.example documents names; no dotenv loader or automatic .env reading exists.
  Current server does not initialize gateway/agent, so setting MODEL_PROVIDER
  alone does not turn /api/generate into AI generation.

CONSOLIDATION EVIDENCE

  model gateway branch 15/15 paths match main blobs; agent branch 19/19; mock
  branch 11/11. Main already contains the feature merges, including enforced
  timeout correction and the noncooperative-provider timeout regression.
  No source overwrite, branch merge or framework migration is needed to recover
  these implementations. Cross-workspace separation follows runtime/feature
  ownership and should remain until a tested integration requires a change.

RECOVERY TEST-DISCOVERY REQUIREMENT
  Replace unconstrained root node --test discovery with explicit trusted active
  test files/roots. Otherwise a future unpacked *.test.mjs under AnalyseFuture
  could be executed. Workspace globs alone do not prevent Node discovering it.
  Keep URL/error/timeout helpers per adapter for now: superficially duplicated
  code has different retry and error contracts and no demonstrated consolidation
  benefit. Do not treat future gateway/agent orchestration as a folder repair.
