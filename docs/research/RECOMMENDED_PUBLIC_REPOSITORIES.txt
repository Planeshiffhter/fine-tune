FINE-TUNE PROJECT — PUBLIC REPOSITORIES FOR STUDY AND REUSE
===========================================================
Last reviewed: 2026-11-15
Project: https://github.com/kawaho3/fine-tune
Purpose: Complete inventory of public GitHub repositories previously recommended
         in this project's ChatGPT planning conversations.

IMPORTANT
---------
This is a RESEARCH INVENTORY, not a list of dependencies installed in fine-tune.
Do NOT copy whole competing products or assume public source means public domain.
Before adoption, pin a revision, inspect source/license/third-party assets,
validate commercial-use terms, security, compatibility, maintenance and costs.
Study/reuse legally licensed components; make our original product modular.
No ranking or feature-parity claim is implied.

Legend:
  CORE CANDIDATE: evaluate as direct library or independently operated service
  STUDY: learn architecture/workflow; don't import an entire fork
  EVALUATE: test alternatives and select ONE
  LATER: defer until justified by product milestones

PRIORITY ORDER FOR OUR PRODUCT
------------------------------
1. Keep the existing offline/mock builder scaffold working and CI green.
2. Review OpenHands SDK + one secure workspace strategy + Ollama provider.
3. Connect Playwright; measure a real prompt-to-build-to-preview-to-export
   workflow with bounded retries and no unrestricted untrusted execution.
4. Add Monaco/shadcn and the appropriate account/data layer.
5. Evaluate ONE structured/code-backed visual editor (Puck vs. Onlook).
6. Add deployment, collaboration, scale-out serving and fine-tuning only when
   the preceding milestones and evaluation suite justify them.

LICENSE / SECURITY WARNINGS
---------------------------
- Public GitHub visibility is NOT an authorization to reuse code.
- The GitHub API did not assert a single standard SPDX license for Dyad,
  Yjs, Langfuse or PostgreSQL; review their actual license texts.
- Licenses may differ by subdirectory, SaaS/enterprise features, runtime,
  assets, models, and versions; legal review is required for commercial use.
- A GitHub repository is not automatically free to host or operate.
- A Docker container alone is not proof of a safe multi-tenant sandbox.
- No repo listed here is automatically integrated into the current product.
